## 6. Stabilise

Before adding anything else:

- [ ] Test the essential user journey from the beginning.
- [ ] Try one awkward but realistic case.
- [ ] Check one existing behaviour for regression.
- [ ] Remove or explain temporary debugging code.
- [ ] Run the project's lint command, if supplied.
- [ ] Run `npm run build`.
- [ ] Review `git status` and `git diff`.
- [ ] Commit and push the latest stable work.
- [ ] Update the GitHub Project board honestly.
- [ ] Record any known problem instead of hiding it.
